# Қыран Көз — снайпер ойыны

Телефонға арналған 2D снайпер ойыны. Бір файл (`index.html`), кітапханасыз, суретсіз: бүкіл графика Canvas-та сызылады, дыбыс WebAudio-мен синтезделеді.

## Ойын туралы

- **Баллистика.** Оқ жылдамдығы 700 м/с, мылтық 100 м-ге нөлделген. Оқ ұшу уақыты `t = d / v₀`, түсуі `½·g·t²`. Практикада: әр 100 м-ге 1 мил жоғары көзде; қозғалатын нысанаға әр 1 м/с жылдамдыққа 1,4 мил алға; желге әр 1 м/с-қа 0,6 мил қарсы.
- **Прицел.** Мил-нүктелі (mil-dot) торап, масштаб ×4 / ×8 / ×12, қашықтық өлшегіш, баллистика кестесі (КЕСТЕ батырмасы).
- **12 кезең:** тұрақты нысаналар → рельстегі қозғалатын нысаналар → ұшып бара жатқан құстар → жел → уақытпен жарыс → аралас емтихан. Одан кейін «Шексіз» және «Күн тапсырмасы» режимдері.
- **Марапат циклі:** «Дәл ортасы!» бағалауы, «Аз қалды! 0,4 мил жоғары» коучингі, серия ×1–×4, дыбыстың қашықтыққа қарай кешігуі, оқ камерасы, кезең сайын 3 сын-тапсырма мен медальдар, дәрежелер (Үйренуші → Мерген → Сұңқар → Қыран Көз), рекордтар, ашылатын прицел стильдері.
- Прогресс браузердің `localStorage`-інде сақталады.
- **Тек көлденең режим.** Портрет режимінде «Телефонды көлденең бұрыңыз» экраны шығады, ойын тоқтап тұрады. Android-та «Бастау» басқанда толық экран мен бағыт бекітілуі сұралады; iPhone-да браузер оған рұқсат бермейді, сондықтан телефонды қолмен бұру керек.

## Басқару

| Телефон | Компьютер |
|---|---|
| Прицелде саусақпен сүйреу — көздеу | Тінтуірмен сүйреу |
| АТУ | Space |
| ДЕМ (демді ұстау, тербеліс азаяды) | Shift (ұстап тұру) |
| 8× батырмасы — масштаб | Тінтуір дөңгелегі |

## Іске қосу

Ешқандай орнату керек емес: `index.html` файлын браузерде ашсаңыз болғаны.

GitHub Pages арқылы жариялау: репо параметрлерінде **Settings → Pages → Branch: master, folder: /(root)** таңдаңыз; ойын `https://<пайдаланушы>.github.io/N-Education/` мекенжайында ашылады. Телефонда «Басты экранға қосу» арқылы қосымша сияқты ойнауға болады.

## Әзірлеушіге

Автотесттер үшін ойын `window.__sniper` API-ін ұсынады: `seed(n)`, `startLevel(i)`, `setAim(az, el)`, `setSway(false)`, `solve(targetId)`, `fire()`, `step(ms)`, `ballistics`, `levels`. Кезең деректері `LEVELS` массивінде, физика константалары файлдың басында.
